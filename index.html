Store & Register

Bahamas VAT is locked at 10% for this register. Receipts print at 3 inches (76 mm thermal).

Cash drawer

Sends the open signal to the receipt printer from this browser (Chrome or Edge). Connect once; the browser remembers it. If your printer is already set to open the drawer when it prints, you do not need this, but this also opens it for cash sales with no receipt.

Staff

Managers see everything. Cashiers can only use the register, sales history, and customers. PINs are a counter-level lock, not strong security.

Data folder (files on this PC)

Pick a folder on this computer, such as C:\POS-Data. Every change is saved to a file there, plus a dated backup copy each day. Works in Chrome and Edge. Use a folder that is also synced to OneDrive or Google Drive, or copy it to a USB stick, for an off-computer copy.

Second backup folder (required)

A second copy of every save goes to a different place, such as a USB stick, another drive, or a OneDrive/Google Drive folder. The POS asks for it each time it starts. It must not be the same folder as the data folder, or inside it.

Backup

Data lives in this browser only. Export a backup regularly and keep a copy off this computer.
